▼   or manually set coordinates to the following variables.
▼   (The coordinates use a center origin and already have coordinate scaling applied.)

▼   the character panel slides from the Start coordinates to the End coordinates.
▼     - 35: Status Display Start X
▼     - 36: Status Display Start Y
▼     - 37: Status Display End X
▼     - 38: Status Display End Y
▼   Note: These coordinates must already have coordinate scaling applied.
